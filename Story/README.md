# 菲比历险记 · 剧情与探索系统

## 本次接入的内容

- 第一至第三章共 27 个子关卡的入场、通关剧情。进入子关卡后入口 NPC 自动开口，暂停战斗并显示选择，不需要移动或按 E。首次是完整介绍，再进入是简短进度提醒，可直接行动或重听完整剧情；旧存档同样适用。
- 剧情按钮提供不同回应与角色情绪语音；选择不扣费，也不影响必需角色、武器奖励。
- 第一章以寻找糯糯、辨别假呼声为主；第二章解释传声装置，并结识坤坤；第三章救出 Doro 和咕嘎，完成四位好友重聚。
- Q 币企鹅明确为玩家操控的临时雇佣兵：仅第三章，3-7 可试用，之后 120 金币预付一场完整挑战。保持现有合同与续档规则。
- 第四章已加入十关音乐救援剧情，数据位于 `Data/chapter4.json`，制作源为 `Tools/author_chapter4_story.py`；完整规则见[第四章制作说明](../Docs/第四章制作说明.md)。
- 通关先保存奖励，再播放剧情，最后询问是否观看视频。关闭、跳过剧情不会丢奖励。奖励已保存但结尾未读完时，重新进入该关会补播。

## 玩家入口

| 操作 | 功能 |
| --- | --- |
| L / 点击左上剧情目标 | 旅程手册：当前目标、已发现关卡、对白回顾、教学清单、剧情语音开关 |
| 进入子关卡 | 自动开始入口 NPC 剧情，直接点击选项 |
| 靠近 NPC 按 E | 自愿使用对应角色的服务，或重听剧情 |
| 点击选择 / 方向键选择后 Enter | 阅读不同态度的回应 |
| Esc | 关闭对白并恢复游戏，记录本段已读；可在手册重看 |

剧情期间暂停战斗。手册不列出尚未访问或通关的关卡。阅读页面有滚动区域，较长操作清单会自动扩大正文区；没有人物头像时释放头像占用的空间。

## 教学、谜语与 NPC

1-1 记录八项真实操作：移动、交谈、普攻、背包、技能、使用药剂、角色大招、开宝箱。首次正常游玩赠送 2 份生命药剂、3 份能量药剂、1 份绝杀药剂，存档记录领取状态，不能反复进图领取。练习不作为通关硬门槛。1-1 的遭遇以普通敌人、补给和向导为主。

第一章每关增加一个谜语和一个暗语机关，共 14 个；其余机关保留原来的电路、方向、压力、前置条件等规则。谜语有备选答案，暗语需要按序输入。答错可重试，提示免费，暗语可清空重输。解题进度、已激活状态与提示进度写入原有存档，不重置已完成机关。

所有子关卡设置 3～4 名不同职责的服务 NPC，共 91 个固定服务位置；被救援角色与随机旅人另计。使用现有中立角色动画，以姓名、服装颜色区分，不增加地形碰撞。位置选择入口附近、已连通的可走区域，并避开门、机关与其他 NPC。

| NPC | 独立职责 |
| --- | --- |
| 入口向导 | 自动讲剧情、任务进度、剧情回顾、旅程手册；不再兼任解谜与商店 |
| 刻文师 | 第一、二章的分层机关提示与刻文解读 |
| 战术员 | 第三章波次、生存条件、当前首领应对与实时战况 |
| 补给员 | 药品、防具、武器交易，沿用价格与等级限制 |
| 医护员 | 1-1、1-6、2-9、3-7、3-9、3-10：每关一次免费恢复当前角色最多 50% 最大生命；满血不消耗，不能复活，使用状态存档 |
| 工匠 | 1-5、2-8、3-6、3-8：付费强化当前武器，上限 +10 |
| 门后旅人 | 随机赠礼与旅途见闻，不再重复入口的任务和机关菜单 |

第三章 E 键选择距离最近的服务 NPC 或被救援角色，避免入口向导截走其他人的互动。

## 语音范围

使用项目已有角色语音库，按实际说话角色与 `dialogue / proud / afraid / angry / victory / battle` 情绪选择片段。玩家切换角色不会改变剧情说话者。对话结束停止剧情语音，可在手册关闭。没有生成逐句对白配音；普通向导使用文字与短提示音。
