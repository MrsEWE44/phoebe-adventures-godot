# 《菲比历险记》剧情草案 v1

> 原始审阅稿，保留供对照。已接入的交互文本以 `Data/campaign.json` 为准，功能说明见 `README.md`。
> 本稿沿用现有解锁节点：1-6 糯糯、2-9 坤坤、3-7 Q 币企鹅、3-9 Doro、3-10 咕嘎。第一章通关后可以继续使用糯糯。

## 一、故事主线

菲比和糯糯约好去遗迹海岸探险。出发前，糯糯收到一张写着“海边有东西落下了”的纸条，先去查看，随后失去联系。

菲比循着糯糯留下的记号进入遗迹。她起初以为，这是朋友准备的一场寻宝游戏。直到空无一人的房间里传来糯糯的声音，而真正的糯糯从不会用那种语气说话。

有人把求救声当成诱饵，将人引入黑门后的封闭空间。海岸只是入口，水下遗迹负责传递声音，冰封王庭才是囚禁者所在的地方。

菲比先找回糯糯，又在水下发现 Doro 和咕嘎也被带走的线索。途中遇见的外来者坤坤成为可靠同伴，陪她们进入第三章。最终，一行人击败奶娃与凑企鹅，救出 Doro 和咕嘎。

这一段故事以“四位朋友终于重聚”结束。坤坤不属于原来的四人朋友圈，却在这次冒险中和她们建立了信任，将接替第四章的旅程。

### 剧情气氛

- 第一章：轻松的寻人探险，逐渐出现不对劲的声音和空间。
- 第二章：在水下寻找原因，补齐第一章的线索，同时建立坤坤与大家的关系。
- 第三章：确认敌人与目标，经历救援和决战，完成朋友重聚。
- 恐怖内容以空房间、错误的回应、重复的脚步、隔门传来的笑声为主。重要战斗危险仍有清晰预警，不靠突然弹脸或无法判断的惩罚制造难度。

## 二、角色关系与说话方式

| 角色 | 关系与定位 | 对白、态度及语音方向 |
| --- | --- | --- |
| 菲比 | 主角；糯糯最亲近的朋友，也认识 Doro、咕嘎 | 调皮，爱逞强，害怕时会嘴硬；涉及朋友安危时认真。不是一直讲笑话。 |
| 糯糯 | 菲比形影不离的好友 | 安静、细心，往往先发现异常；用短句提醒，不长篇解释。 |
| 坤坤 | 第二章遇见的外来者 | 初见有戒心，遇事愿意出力；篮球动作与口头反应保留个人特色，严肃场景不过度插科打诨。 |
| Doro | 菲比的朋友 | 声音以“doro”“欧润及”的不同语气表达；文字通过表情和动作补充含义，不让她突然说一大段流利对白。 |
| 咕嘎 | 菲比的朋友 | 情绪直接，获救时会先确认同伴；用短促叫声、点头、张开翅膀表达态度。 |
| Q 币企鹅 | 第三章付费出战的外援，不是原四位朋友之一 | 有自己的交易原则，办事直接。获得资格后由玩家操控，按现有规则仅第三章可用。 |
| 奶娃 | 用笑声、音波与禁锢妨碍救援的敌人 | 幼体、小 BOSS、完全体共用完整语音；区别放在技能和演出，不另造三个人格。 |
| 凑企鹅 | 冰封王庭最终看守者 | 通过投石、陨石、飞踢阻止救援；与 Q 币企鹅明确区分。各阶段共用同一套声音，完全体才有全部技能。 |

## 三、第一章：海岸那头的回声

**核心目标：学会操作 → 寻找糯糯 → 识破假声音 → 救回好友 → 找到通往水下的入口。**

### 开场：一次没有等到人的约定

海岸集合地点只有一个背包。背包旁，糯糯留下半张纸条：

> “我先去看看。你来了以后，沿着……”

后半段被水打湿了。菲比认出附近石头上有糯糯画的小记号。

菲比：「又抢先出发。等找到你，这次零食你请！」

**弹窗选择**

| 按钮 | 对白与态度 | 语音 | 后续 |
| --- | --- | --- | --- |
| 「沿着记号找她」 | 菲比：「好，看看你藏了什么宝贝。」轻快、好奇。 | 好奇短句 | 标记 1-1。 |
| 「先检查背包」 | 菲比：「连备用的药都没带？这可不像你。」笑意收起。 | 担心短句 | 提前提示补给用途，再标记 1-1。 |

两种选择都能正常开始，不设置开局选错就损失物品的惩罚。

### 1-1：糯糯留下的小路——完整的新手教学

这一关暂不安排强烈恐怖演出。玩家在一条能看清前方的路线中，逐步完成操作。

| 剧情节点 | 玩家操作 | 弹窗与反馈 |
| --- | --- | --- |
| 看见记号 | 移动到路标附近 | 「跟上记号」；提示 WASD，一次只教一个操作。 |
| 遇见守路人 | 靠近并按 E | 守路人：「那个安静的小姑娘？她往里面去了。先别急，你会用这些东西吗？」 |
| 学习瞄准 | 对练习目标普通攻击 | 「试试攻击」「再解释一次」；提示鼠标瞄准、左键攻击。 |
| 第一次小规模战斗 | 击败少量敌人 | 战斗开始前结束对话，不用弹窗挡住攻击预警。 |
| 补给教学 | 拾取药品、打开背包并使用 | 有可恢复的生命缺口再教回血；满血时不要求浪费药品。提供练习用药品。 |
| 技能教学 | 使用右键技能，再认识 F 大招 | 提供足够练习能量；说明角色技能与武器绝招不同，当前没有武器绝招时只介绍用途。 |
| 宝箱与出口 | 开箱，查看所得物品，完成出口交互 | 提示图标、数量、用途与出口解锁条件。 |

**守路人的按钮**

- 「从头教我」：守路人耐心讲解；菲比轻快回应：「行，今天就让你当一回老师。」
- 「我想先试试」：缩短说明，保留目标提示；菲比得意：「看好了，我学得可快了！」
- 「药品怎么用？」：打开对应教学段；菲比认真确认，不播放得意或战斗叫声。

通关小结：

> “你已经学会移动、攻击、交谈、使用补给和释放技能。接下来，跟着糯糯的记号继续寻找她。”

结尾只有一个小异常：菲比离开后，空路口传来另一组脚步声。此时不强制战斗。

### 后续关卡走向

| 关卡 | 剧情事件 | 探索与解谜方向 | 结尾推进 |
| --- | --- | --- | --- |
| 1-2 失约的营地 | 找到糯糯停留过的地方，食物和灯都没收走。 | 比较物品与足迹，第一次让 NPC 提供线索而非直接给答案。 | 发现糯糯离开时很匆忙。 |
| 1-3 门后的声音 | 黑门后有人用糯糯的声音叫菲比过去。 | 用之前见到的习惯和记号核对路线；声音只能作为线索，不能直接当答案。 | 首次确认存在模仿求救声的东西。 |
| 1-4 没有人的回话 | NPC 提醒：“别回答没有名字的人。”菲比却听见有人叫出自己的名字。 | 找到相互印证的两条线索，破解机关顺序；给错误操作可恢复的反馈。 | 获得有关“水下传声”的残页。 |
| 1-5 糯糯的暗号 | 正常路标消失，转而出现只有菲比认识的小标记。 | 多个机关彼此关联，先确认真线索，再安排开门顺序。 | 菲比确认糯糯还活着，而且在主动留下信息。 |
| 1-6 隔门相认 | 找到被封印隔开的糯糯。 | 完成救援目标、解除所有必要封印。 | 解锁糯糯，可立即切换体验。 |
| 1-7 两个人的归路 | 两人准备离开，海岸出口再次被封；水面下传来同一段假声音。 | 用前面学会的观察、机关和战斗完成章节收尾，不强制用某个角色才能过。 | 打开通往水下遗迹的路线，第一章通关。 |

### 关键弹窗：1-3，假的糯糯

门后：「菲比，别看那些记号。过来，我就在这里。」

菲比：「……糯糯可不会叫我别看路。」

| 按钮 | 菲比反应 | 语音与反馈 |
| --- | --- | --- |
| 「问一个只有她知道的问题」 | 「我们出门前，谁偷偷吃了最后一块点心？」 | 故作轻松；门后停顿，露出破绽，得到直接线索。 |
| 「退后，检查门边」 | 「先等一下，我鞋带松了。」 | 压低声音、害怕；镜头提示附近异常记号，获得另一条线索。 |
| 「你根本不是她」 | 「学得还挺像。可惜，差一点！」 | 生气、挑衅；门后响起怪声，出现短暂危险预警，随后进入可应对的战斗。 |

不同选择改变演出和获取线索的方式，不永久封死主线。

### 关键弹窗：1-6，终于找到你

真正的糯糯：「菲比。别踩左边那块石头。」

菲比低头，看见石缝里还没有熄灭的封印。

菲比：「……这回是你了。别人装你的时候，都没记得先管我会不会摔跤。」

救援完成后：

| 按钮 | 对话 | 语音 |
| --- | --- | --- |
| 「扑过去抱住她」 | 菲比：「下次不许一个人先跑了！」糯糯：「嗯。一起走。」 | 菲比松口气、带一点委屈；糯糯温柔短句。 |
| 「故意装作生气」 | 菲比：「知道我找了多久吗？」糯糯：「知道。你的声音，我一直听得见。」 | 菲比先嗔怒后放软；糯糯平静、歉意。 |
| 「先问她有没有受伤」 | 菲比：「能走吗？我扶你。」糯糯：「能。你也受伤了。」 | 两人关切，避开庆祝式大喊。 |

随后显示角色解锁弹窗：「糯糯加入队伍」，按钮为「切换糯糯」「继续使用当前角色」「查看角色」。

### 第一章尾声

糯糯解释：她看见有人落入水中，追过去时被黑门困住。隔着封印，她还听过另外两个熟悉的声音。

菲比：「Doro……还有咕嘎？」

糯糯：「我不能确定。所以，我们得亲自去看。」

菲比：「那就去。找到一个了，剩下的也要找到。」

## 四、第二章：沉在水下的消息

**核心目标：解释海岸异变 → 找到另外两位朋友的去向 → 结识坤坤 → 进入冰封王庭。**

下水前给一个简短确认弹窗，告诉玩家这里有水生敌人和环境适用装备；已完成的第一章教学不重复铺开。

| 关卡 | 主要剧情 | 玩家会知道什么 |
| --- | --- | --- |
| 2-1 入水的第一盏灯 | 水下引路人教玩家辨认安全路线和水生敌人。 | 水下不是偶然形成的洞穴，这里曾有人维护。 |
| 2-2 潮汐仓库 | 发现与第一章营地相同的物资标记。 | 两处遗迹曾经相通。 |
| 2-3 传声装置 | 拆解一组会重复求救声的装置。 | 第一章门后的声音通过这里传播；并非每一次呼救都来自真人。 |
| 2-4 被改写的留言 | 一份留言先写“返回”，后来被改成“继续向前”。 | 有人故意把寻人者引向更深处。 |
| 2-5 两种熟悉的声音 | 短暂听到 Doro 的叫声与咕嘎的回应。 | 两位朋友曾经过这里，但声音的时间顺序不对，不能认定他们还在本关。 |
| 2-6 旧水闸 | 关闭干扰后，得到完整路线记录。 | 囚禁者已经被转移到更高、更冷的地方。 |
| 2-7 路不只有一条 | 帮助受困者，从 NPC 口中拼出押送过程。 | 不同 NPC 各掌握一部分信息，闲聊与重要线索有明确区分。 |
| 2-8 不属于这里的声音 | 深处传来有规律的“咚、咚”声，与回声装置不同。 | 有人仍在主动发信号，是篮球撞击墙面的声音。 |
| 2-9 把球传过来 | 找到被困的外来者坤坤，一起完成脱困。 | 坤坤加入，知道通往冰封区域的出口位置。 |
| 2-10 通向寒冷的出口 | 坤坤与伙伴们突破最后一道水下封锁。 | 找到第三章入口，确认 Doro 和咕嘎被带往冰封王庭。 |

### 关键弹窗：2-9，第一次见面

篮球从裂缝后滚出来，停在菲比脚边。

坤坤：「先别碰那边的机关。球，传过来。」

菲比：「你被关在里面，还指挥上了？」

| 按钮 | 对话与态度 | 声音反馈 |
| --- | --- | --- |
| 「先把球传给他」 | 坤坤接住球，试探机关间隙。菲比：「接稳了！」 | 菲比爽快；坤坤轻快回应，接球声。 |
| 「你是谁？」 | 坤坤：「路过的。现在大概算迷路的。」菲比：「巧了，我们正在找人。」 | 菲比警惕转好奇；坤坤无奈短句。 |
| 「你能帮我们找到朋友吗？」 | 坤坤：「先出去。路上看到的，我都告诉你们。」 | 认真、合作，不提前宣布已经熟悉彼此。 |

完成关卡后解除拘束，显示「坤坤加入队伍」。

糯糯：「你不是从海岸来的。」

坤坤：「不是。不过现在，我们应该顺路。」

菲比：「行，那就一起。球别砸到我就好。」

此处可以选「切换坤坤试试」「让他先休息」「查看篮球技能」。选项只改变当前出战安排，不取消角色解锁。

### 第二章尾声

水下装置停转后，一段不再失真的短录音响起。Doro 叫了两声，随后是咕嘎急促的回应与铁门关闭的声音。

糯糯：「这次是真的。」

菲比：「那我们就不能停了。」

坤坤把球夹在臂弯，跟上两人的脚步。

## 五、第三章：把朋友带回家

**核心目标：确认囚禁位置 → 突破分层守卫 → 救出 Doro → 救出咕嘎 → 四位朋友重聚。**

波次规则成为剧情的一部分：每座冰门后都有必须清除的守卫。攻击一轮结束后，玩家才能得到短暂喘息。普通关卡仍沿用现有波数；剧情不额外增加强制等待。

### 入场对白：谁都不能少

菲比：「糯糯，Doro，咕嘎，还有我。我们四个，一个都不能少。」

坤坤：「那我呢？」

菲比看了看他怀里的篮球。

菲比：「你也一起。回去请你吃饭。」

糯糯：「先把人带出来。」

### 关卡推进

| 关卡 | 剧情与气氛 | 与既有关卡规则的结合 |
| --- | --- | --- |
| 3-1 门前的约定 | 找到刻在冰门上的押送记号。 | 两波教学式防守，介绍波次与出口。 |
| 3-2 回不去的门 | 来路被封，只能清除守卫继续前进。 | 完成战斗后开放出口，不用剧情对白假装存在另一条实际不可走的路。 |
| 3-3 笑声的主人 | 首次看见奶娃小 BOSS，听到第一章就出现过的笑声。 | 识别禁锢和减速；从此出现奶娃幼体。 |
| 3-4 守卫的记录 | 找到写有两名囚禁者特征的记录。 | 确认 Doro 和咕嘎仍在不同区域，休整时可查看线索。 |
| 3-5 没有停下的笑声 | 奶娃完全体挡住前路，过去的恐惧终于有了具体形体。 | 强调音波范围预警、打断与补给，不用长对白占据战斗。 |
| 3-6 第二道封锁 | 发现一份未完成的共振武器研究记录。 | 为 3-9 的克制枪铺垫，但此关不提前发武器。 |
| 3-7 冰原上的交易 | Q 币企鹅提出共同突破围攻，战后再谈后续出战费用。 | 坚持三分钟并击败小 BOSS；保留免费试用、通关后付费出战。 |
| 3-8 牢笼的位置 | 找到指向两座牢笼的最后线索，守卫明显增强。 | 提醒补给与武器强化，为连续救援做准备。 |
| 3-9 四分钟后开门 | Doro 被封在入口牢笼内；解除封印需要至少四分钟，还要清除守卫。 | Doro 免伤，不是护送或保卫血条玩法；满 240 秒后清场，解锁 Doro 和共振枪。 |
| 3-10 最后一个人 | 咕嘎在最终牢笼内，凑企鹅完全体拒绝放行。 | 无时间限制，击败所有必需首领，解锁咕嘎并继承石头和全部相关技能。 |

### 关键弹窗：3-7，外援的条件

Q 币企鹅：「先过眼前这一关。后面的路，我出力，你付钱。」

菲比：「你连救人都要算账？」

Q 币企鹅：「弹药要钱。不过今天这场，先帮你们打完。」

| 按钮 | 语气与信息 | 玩法承接 |
| --- | --- | --- |
| 「好，先一起出去」 | 菲比干脆；Q 币企鹅认可。 | 进入本关试用说明。 |
| 「先说清楚怎么算」 | 菲比谨慎；Q 币企鹅解释规则。 | 明确后续每场费用、第三章限制及由玩家操控。 |
| 「这次谢谢你」 | 菲比诚恳；对方略显得意。 | 同样开放试用，不因态度不同加价。 |

通关后的付费选项必须显示实际游戏币价格；金币不足也能继续主线，不把雇佣当成救朋友的硬门槛。

### 关键弹窗：3-9，Doro 听见了

菲比靠近牢笼。里面的 Doro 抬起头，迟疑地叫了一声。

Doro：「……doro？」

菲比：「是我。这次不是假的声音。」

糯糯查看封印：「机关已经启动。四分钟。守卫不清掉，锁也不会开。」

| 按钮 | 菲比的态度 | Doro 的声音与动作 |
| --- | --- | --- |
| 「别怕，我们在这里」 | 温柔、安抚。 | 轻声“doro”，靠近栏杆，紧张缓解。 |
| 「看我把门打开」 | 自信，带一点熟悉的调皮。 | 上扬的“欧润及”，点头回应。 |
| 「告诉我们，咕嘎在哪」 | 焦急但克制。 | 急促两声“doro”，指向更深处；文字描述动作，不替语音编成长句。 |

开始战斗后，剧情不再自动弹窗暂停。到达阶段时间可以出现一行简短提示，例如「封印正在减弱」，同时播放一句简短反应，避免连续语音盖住危险音效。

通关后：

Doro 跑出牢笼，先抓住菲比，再拉住糯糯。她回头，急切地指向最后一道门。

菲比：「知道了。我们一起去接他。」

此时发放静音共振枪。研究记录补齐说明：这把枪能破坏奶娃、凑企鹅的共振防护，因此造成无视防御的伤害，并连带附近敌人。提示按钮为「查看武器」「查看 Doro」「继续救援」。说明 Doro 仍只能使用橘子，共振枪由可装备它的队员使用。

### 关键弹窗：3-10，最后的牢笼

咕嘎被关在冰封王庭的最后一座牢笼里。看见同伴，他用翅膀敲了敲栏杆。

菲比：「听见了，别敲了。我们这就过来。」

凑企鹅的笑声压过回应，一块石头砸在两人之间。

| 按钮 | 菲比反应 | 声音态度 |
| --- | --- | --- |
| 「把我的朋友还回来」 | 正面回应看守者。 | 愤怒、坚定。 |
| 「先确认大家的状态」 | 「药、能量、武器。都准备好，我们一起进去。」 | 克制、认真；可先查看背包再开战。 |
| 「咕嘎，再等我们一下」 | 面向牢笼，而不是敌人。 | 关切；咕嘎短促回应，表示听见。 |

战斗中，奶娃与凑企鹅按现有阶段使用技能。凑企鹅完全体召唤四只奶娃完全体时，使用短字幕和角色警告，不弹出需要点击才能关闭的剧情窗。

### 第三章结局：一个都没少

全部必需首领倒下，牢笼打开。咕嘎走出来，张开翅膀，把几个朋友挤成一团。

菲比：「好了好了——挤到我了！」

她说完，却没有松手。

糯糯：「这次，都在。」

Doro：「Doro！欧润及！」

咕嘎发出高兴的叫声，抬脚把地上的小石头踢开。那块属于凑企鹅的原石随后落在他面前。

菲比：「这回轮到你拿它保护大家了。」

**角色与奖励弹窗**

> 咕嘎企鹅加入队伍。
>
> 获得专属武器：凑企鹅原石。
> 继承：投石、碎石雨、陨石、飞踢。
> 咕嘎在所有关卡固定使用原石，不可更换或丢弃。

**章节完成弹窗**

> **菲比的朋友们，终于全部集齐了。**
>
> 菲比、糯糯、Doro、咕嘎，一个都没有少。
> 这一段寻找朋友的冒险，到这里告一段落。

结局按钮：

- 「看看大家」：四位朋友依次播放轻快的重聚回应；坤坤在一旁松口气，菲比招呼他靠近。
- 「谢谢一路帮忙的人」：菲比认真向坤坤道谢，坤坤用简短回应接下，不用长篇独白抢走重聚时刻。
- 「继续」：进入是否播放通关视频的选项。

随后单独显示：「播放通关视频」「不播放，继续游戏」。视频原声正常播放，游戏音乐、对白和音效暂时静音，关闭后恢复。奖励在此之前已经获得，选择不播放不会损失内容。

在第三章结束后的章节预告中，明确告诉玩家：

>

> 第四章尚未开放。

按钮只需「知道了，返回主场景」。不在第三章通关后立刻剥夺玩家刚解锁角色的使用权；四位角色的限制只针对将来的第四章。

你提到“这四个在第一关后就会离开”，与前文的第三章集齐、第四章换主角存在时间点歧义。本稿先采用明确的玩法要求：第四章四位朋友不可用、坤坤接替；具体在第几关离队以及如何离队，暂不写死，等你审阅后确定。

## 七、弹窗、按钮与语音的整体规则（供审阅）

### 一次只推进一个重点

开场交代目标，路上用短反应，休整时补线索，结尾承接下一关。没有新信息的普通战斗不重复打断玩家。

每个关键节点采用以下形式：

1. 弹窗显示说话者、短对白和当前情绪。
2. 玩家选择两到三个有实际区别的态度或行动按钮。
3. 播放对应回应，并显示相应文字；不只换一句提示而播放同一条声音。
4. 更新简短目标，例如“寻找糯糯留下的第二个记号”，让玩家知道接下来要做什么。

### 态度与声音

| 选择态度 | 适用声音 | 避免的问题 |
| --- | --- | --- |
| 调侃、逞强 | 轻快、得意、故作镇定 | 朋友受伤时不突然播放大笑。 |
| 安慰、关心 | 轻声、温柔、担忧 | 不把受伤叫声当安慰回应。 |
| 怀疑、询问 | 谨慎、疑惑 | 不因普通提问触发生气。 |
| 对敌人强硬 | 愤怒、坚定 | 同样是大声，区分战斗怒吼与惊吓。 |
| 退后观察 | 害怕、压低声音 | 害怕不是失败路线，也不会取消奖励。 |
| 团聚、感谢 | 松口气、高兴、温和回应 | 避免多个人同时长时间说话。 |

剧情对白中的菲比按原始人物身份说话；玩家当前操控糯糯、坤坤或其他角色时，也不能把菲比的台词和语音误挂给当前角色。需要菲比发言的段落由剧情弹窗标明说话人。

Doro 的语音保持“doro / 欧润及”；咕嘎的回应以已有叫声和情绪音为主。新写的完整对白只是配音稿，尚未生成音频。实际制作前逐条核对现有素材；找不到语义相符的音频时，不拿内容不相干的旧台词硬配。

### 不因剧情造成操作困难

- 强制剧情只在安全节点暂停战斗；战斗中使用不挡视线的字幕和短语音。
- 支持跳过已看过的对白、重看重要线索、关闭自动语音。
- 跳过演出仍获得奖励、记录线索并更新目标。
- 按钮决定态度、提示详略和局部演出；本版主线不做永久错过角色或无法继续的分支。
- 奶娃、凑企鹅沿用各自全阶段通用语音。新剧情不改变已确定的阶段技能边界。
- 屠龙刀属于已有武器，技能仍叫雷霆半月斩；剧情不另行创建重复武器。
