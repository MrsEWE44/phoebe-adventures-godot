## 最终战与失败恢复

最终首领有合奏护幕，普通攻击最多压到15%生命；合奏完成后才能彻底击败。召集不消耗大招药剂，避免进入关卡时没有次数导致卡关。三名演奏者全部就位后，仅坤坤可操控；任一演奏者倒下会弹出失败界面，可重试本关或返回主图准备。

存档保存波次、击败记录、首领状态、同化队友生命、召集席位、保护计时、角色形态及是否看过剧情影像。失败后重进也会显示恢复选项。角色与剧情奖励只能获得一次。

同时在场敌人上限32，普通同化队友上限4；4-10乐队音波转化奶娃不受此队友上限限制。召唤采用代际限制，避免完全体无限递归召唤；保留召唤与密集战斗的玩法。4-8、4-9、4-10主凑企鹅分别提升基础生命倍率至1.5、2、3倍，并增加攻击/防御。

## 编辑碰撞、道路与出生点

1. 在Godot打开 `Scence/Levels/level_28.tscn`～`level_37.tscn`。
2. 选择 `Terrain/RoadBoundary`，编辑 `CollisionPolygon2D` 顶点。它是围绕道路与舞台外边缘的闭合线段碰撞，空地不铺满方块。
3. `Terrain/WallOrGrave_*` 是内部墙面/墓碑实体碰撞，可单独调整。每关1条外边界，另有0～2处内部障碍。
4. `Spawn`、`ArenaCenter`、`RescuePosition`、`EnemySpawns`、`Portals`、`Chests` 均可在场景中调整。
5. 主图使用 `Terrain/RoadBoundary_0..2` 三条道路外缘/环路边界，共174个顶点。按 F3 查看碰撞与可行走区域；按 M 查看地图路线。
6. 新敌人碰撞在 `Characters/Actors/tensura_*.tscn` 与 `weiro_*.tscn` 中：`FootCollision` 控制行走，`Hurtbox/CollisionShape2D` 覆盖全身受击。
7. 被囚角色的牢笼使用共享 `Scence/Chapter3/cage.gd`：包含前景栏杆、交叉金属锁链和黄铜挂锁。第四章在 `Scence/Chapter4/ally.tscn` 的 `Cage` 节点调整尺寸与颜色，编辑器可直接预览；普通友军不显示牢笼，救援完成后随牢笼一起移除，不增加行走碰撞。第三章Doro、咕嘎开笼时自动隐藏锁链。

运行时 `geometry.gd` 只读取这些场景节点建立寻路，不创建地图碰撞。`Tools/author_chapter4.py` 是离线制作源，**重新运行会覆盖生成的场景/资源**；编辑器调整后应同步制作源，或保留编辑后的场景，不要直接重新生成。
