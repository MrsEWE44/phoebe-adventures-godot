# 菲比历险记 · 项目说明

更新日期：2026-10-11。本文整理当前代码实现，作为项目总览；美术目录里的生成记录和旧设计草稿不代表现行规则。前两章本次调整见[前期关卡整理](前期关卡整理.md)。

## 1. 项目概况与启动

- 类型：Godot 2D 俯视角动作冒险，组合探索、谜语机关、角色救援与波次战斗。
- 当前内容：5 个大关主场景、47 个子关卡；第四章为音乐救援、叛变与保护合奏，第五章为地狱救援与时空胶囊分支。第五章详见[制作说明](第五章制作说明.md)和[完整剧情](第五章剧情.md)。
- 工程入口：根目录 `project.godot`，Godot 工程名仍为 `MyGame`；默认运行 `Scence/Main.tscn`。
- 本次使用 Godot **4.7.2** 验证。默认画布 1280×720，项目配置为 Mobile 渲染；兼容预览可通过 `--rendering-method gl_compatibility` 启动。
- 在 Godot 导入 `project.godot`，等待资源导入完成，按 F5 运行整个游戏；F6 运行当前打开的场景。
- 正常无存档启动与“重置存档 / 重新开始”均从 **1 级**开始。自动化测试仍可显式使用 30 级测试档；已有存档沿用等级，不会因更新自动重置。

命令行示例（将 `godot` 替换为自己的 Godot 控制台程序路径）：

```powershell
godot --path .
godot --path . --rendering-method gl_compatibility
godot --headless --path . --script Tests/experience_item.gd
```

| 第二章 | 2-1～2-10 | 水下遗迹补齐传声装置线索，寻找 Doro 与咕嘎的踪迹，结识坤坤 | 20 级；第一章主图南侧海洋触发入口 |
| 第三章 | 3-1～3-10 | 冰封王庭波次挑战，救出 Doro、咕嘎，完成好友重聚 | 30 级；第二章主图右下通道传送门 |

| 第五章 | 5-1～5-10 | 地狱救援、音乐队离场、奥摩胶囊分支、四小只重聚 | 50级；第四章主图出口 |

第三章入口锁定，清完一波才开始下一波。3-1 从两波开始，后续逐步增加，上限五波。成功后右上出口允许进入下一关或返回主图。

| --- | --- |
| 1-1 | 自动剧情引导；练习移动、对话选项、普攻、背包、药剂、技能、大招、宝箱。首次教学赠送补给，不能重复领取 |

| 3-10 | 没有生存倒计时；清波次并击败奶娃、凑企鹅的小 BOSS 与完全体，救出咕嘎；凑企鹅完全体可召唤四只奶娃完全体 |

进入第四章永久解锁无限传送卷轴，可从背包“道具”页或Esc菜单前往满足等级要求的第一～第五章主场景。子关卡Esc菜单允许随时保存进度并返回本章主场景，或重新挑战本关并保留等级装备；无需先通关。前两章已通关关卡也可重新挑战，重新生成机关与战斗，保留后续入口解锁，不重复领取首次通关奖励。

### 剧情触发与 NPC

进入任一子关卡，入口向导自动讲剧情并显示选项，**无需靠近 NPC**。首次完整介绍，再次进入简短提醒，可主动重听。旧存档适用；未读完的通关剧情可以在重新进入时补播。

前两章每关3～4名固定服务NPC，被囚禁角色与随机旅人另计。NPC为中立角色，不承受阵营伤害，也不阻挡道路。当前使用已有角色动画，以姓名、服装颜色和职责标识区分。

| 角色分工 | 服务 |
| --- | --- |
| 入口向导 | 自动剧情、当前目标、进度、手册 |
| 刻文师 | 前两章的逐层机关提示、刻文解读 |
| 战术员 | 第三章首领预警、波次与生存条件 |
| 补给员 | 药品、防具、经验结晶与商店武器 |
| 医护员 | 1-1、1-6、2-9、3-7、3-9、3-10；每关一次免费恢复当前活着角色最多 50% 生命，满血不消耗次数 |
| 工匠 | 1-5、2-8、3-6、3-8；付费强化当前武器 |
| 门后旅人 | 随机赠礼、强化机会或闲聊，不重复入口菜单 |

角色对白选择使用现有情绪语音片段，不是整篇剧情的逐句配音。普通服务 NPC 使用文字与短提示音。

## 4. 角色与专属能力

所有人物继承 `Characters/character_base.gd`；玩家共用 `Characters/playable_character.gd`，定义资源、动画、语音与大招分别维护。类型分为玩家、敌人、中立 NPC、BOSS。

| 角色 | 获得方式 | 装备与特征 |
| --- | --- | --- |
| 菲比 | 初始角色 | 调皮；与糯糯、Doro、咕嘎为好友；可装备通用武器 |
| 糯糯 | 1-6 救援 | 安静；陆地环境能力强化；可装备通用武器 |
| 坤坤 | 2-9 救援 | 仅篮球；随机直线传球或运球爆破，水下加成 |
| Q 币企鹅 | 3-7 试用，通关后可付费雇佣 | 仅第三章、玩家操控；120 金币预付一场完整挑战；只用 AK47，贯穿弹头沿瞄准方向攻击一行敌人，15 秒冷却 |
| Doro | 3-9 解锁 | 400 点基础生命；仅橘子武器，追踪、爆炸与范围技能 |
| 咕嘎企鹅 | 3-10 解锁 | 150 点基础生命；固定使用凑企鹅原石，不能换成其它武器或丢弃；投石、碎石雨、陨石、飞踢及角色突进 |

等级和经验全队共享，角色生命与大招次数独立。当前角色死亡后优先切换存活队友；全队倒下时可重新挑战或退回主图。复苏晶石需 40 级商店购买，只能回主场景后复活角色。

## 5. 等级、经验与物品

### 成长公式

- 最高 100 级。普通角色 1 级基础生命 100、攻击 20、防御 10、能量 200；角色资源可定义不同基础生命。
- 每提升一级增加 **5 生命、1 攻击、0.5 防御**。升级保留各角色原有生命比例，死亡队友仍保持死亡。
- 普通敌人基础奖励 12 经验，BOSS 基础 65；击杀低于玩家等级的敌人时经验递减，最低 1。
- 升级需求：1～19 级每次 100；20～29 为 140；30～39 为 196；此后每十级乘 1.4 并向上取整。
- 第二章门槛20级，第三章30级，第四章40级，第五章50级。后续章节门槛按章节数×10，上限100；目前实际地图到第五章。

### 新增经验结晶

| 项目 | 内容 |
| --- | --- |
| 物品 ID | `experience_crystal` |
| 效果 | 每颗 **+100 经验**，直接加入成长系统，不受击杀等级差折扣影响 |
| 获取 | 概率掉落；商店 1 级开放，**80 金币 / 颗** |
| 使用 | B → 道具 → 经验结晶 → 使用；图标、数量、经验与等级立即刷新 |
| 限制 | 当前角色死亡时不能使用；100 级时不消耗。升到 100 级后的多余经验不保留 |
| 存档 | 数量保存在 `profile.bag`，使用扣除和经验写入同一次存档 |

现行药品包括生命药剂、能量药剂、绝杀药剂、大型生命药剂、大型技能瓶、全效秘药、复苏晶石。装备包括护甲、护符、深潜护甲、重甲、鞋子和守护晶核；装备槽区分身体、脚部、饰品。

普通怪掉落概率约 24%，BOSS 约 65%；掉落候选包含药品、经验结晶、装备和允许的章节武器。经验结晶是候选之一，并非每次击杀必得。

## 7. 地图、碰撞与资源编辑

主场景：`Scence/Main.tscn`、`Scence/Chapter2.tscn`～`Scence/Chapter5.tscn`。第一章地形嵌套在 `Scence/level1.tscn`。

子关卡统一为`Scence/Levels/level_01.tscn`～`level_47.tscn`：1～7对应第一章，8～17第二章，18～27第三章，28～37第四章，38～47第五章。配置在同目录`data/level_XX.json`，原始背景在`Maps/Level1`～`Level5`。

地形碰撞保存在 `.tscn`，可直接在 Godot 2D 编辑器修改。运行时 `geometry.gd` 读取现有碰撞用于寻路，不生成替代地形。第一、二章编辑 `Terrain`、`Doors`、`Switches`、`Traps`、`ReturnPortal`、`Spawn`；第三章另有 `ArenaCenter`、`EnemySpawns`、`Portals` 等节点。修改前确认门、出生点和可走路线仍连通。

前17个子关卡现与第三章统一：`Terrain/FloorBoundary_*`为`CollisionPolygon2D`，Build Mode为Segments，仅边缘阻挡，内部可走。地形节点由2403个矩形块合并为49条闭合轮廓；门与陷阱继续单独编辑，不与道路合并。

奶娃与凑企鹅各形态的角色碰撞在 `Characters/Actors/*.tscn` 中，可编辑全身命中框与移动碰撞。NPC 服务角色通过 `Story/npc_roster.gd` 分配到现有可达区域，不新增地形碰撞。

地图分类使用 `land / ocean / sky / snow` 等环境标识；角色家园加成由角色定义与场景开关决定。地图编辑工具会写场景文件，使用前应备份当前手工修改。

| --- | --- |

| `Docs/` | 当前项目说明、验证记录、清理清单 |

自动加载顺序：Storage → Global → Campaign → Dialogue → Story。

新增人物继承公共角色类，新增定义、动画、语音、大招资源并配置类型；新增武器继承 `weapon_definition.gd`，注册资源后仍须明确放入商店、章节名单或角色装备。不能仅把武器脚本放进目录就让所有章节随机掉落。

新增物品从 `Combat/items.gd` 开始，同时检查商店、库存读写、使用条件、使用效果、背包分类和测试。经验结晶可作为新增消耗道具的完整范例。

- 音量配置位于 `Data/Settings`，历史备份位于 `Data/Backups`，运行日志位于 `Data/Logs`。旧系统目录的数据仅首次读取迁移，不再作为游戏保存位置，详见[数据目录说明](数据目录说明.md)。
- 保存角色状态、等级经验、背包、强化、已开机关与门、战斗进度、剧情选择、服务使用记录等。
- 重置存档需确认：清除进度、解锁、装备、金币、经验结晶等，从第一章 1 级重开；音量设置保留。
- 对旧等级和武器数据进行迁移；被删武器不会导致角色装备栏悬空。更新代码不会直接覆盖当前玩家的用户存档；迁移在游戏读档时发生。
- 音频分为 Music、Voice、EnemyVoice、Effects、Video，暂停设置可独立调节敌人声音。奶娃与凑企鹅各阶段共用完整语音库，技能按阶段区分。
