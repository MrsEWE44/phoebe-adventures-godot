# 前两章关卡整理 · 2026-10-11

## 已修改的范围

编号1～17对应1-1～1-7、2-1～2-10；此次统一这些子关卡的地形结构，主场景地形没有重做。第三章以后原有的波次、角色解锁和剧情规则保留。

### 地形与互动

- `Scence/Levels/level_01.tscn`～`level_17.tscn`使用与第三章相同的`CollisionPolygon2D`边界，位于`Terrain/FloorBoundary_*`，Build Mode为Segments。道路内部不填满碰撞块，水池／缺口保留独立内轮廓。
- 2403个矩形碰撞节点合并为49条闭合轮廓。这个数字指场景节点，不代表物理线段数量或帧率提升倍数。
- 补通1-2上方废墟封印门的石道；第二章恢复按地图描绘的道路边界，封住2-10原有的外围漏口；恢复2-10一个缺少碰撞形状的喷口。
- 门仍在`Doors/*/Barrier`单独编辑。互动距离改为测量门的碰撞边缘，修复碰撞位置偏移后无法靠近原点开门的问题。
- `Switches`、`Traps`、`Spawn`、`ReturnPortal`、宝箱位置仍独立保存。运行时只读取场景碰撞来建立寻路，绝不重新生成实体地形。

**在编辑器中修改**：打开对应`.tscn` → 展开`Terrain` → 选择`FloorBoundary_*` → 在2D视图编辑顶点。保持闭合，不要把Build Mode改为Solids，否则会把整块道路填成障碍。门、陷阱无需并入道路轮廓。保存后运行`Tests/expedition_routes.gd`检查机关、门、宝箱、NPC与出口是否可达。

离线迁移脚本为`Tools/author_early_contours.py`；默认跳过已转换的关卡。脚本依赖迁移时的`.godot/navigation_baseline.json`与备份，只供此次迁移维护；后续直接编辑场景即可，不需要运行它。备份与诊断图不作为游戏运行资源。

- 前期明确普通攻击、技能能量与F大招次数的区别；解释免费谜题提示、背包换装、水生克制、药品快捷键和专属角色武器限制。
- 1-6明确清场、开门后需要与糯糯交谈救援；2-9明确坤坤只能使用篮球，其他武器仍留在共享背包。

- 运行时文本为`Story/Data/campaign.json`；本轮文本修订工具为`Tools/polish_early_story.py`。

### 武器、专属规则与道具

- 第一章仍仅产出青铜短剑、遗迹手枪；第二章仍仅产出珊瑚三叉戟、潮猎鱼叉枪。商店武器和角色自带武器保持原有独立规则，没有增加章节武器种类。
- 1-1首次向导引导提供短剑，东侧固定宝箱提供遗迹手枪；2-1首次引导提供三叉戟，原有宝箱提供鱼叉。引导赠送按存档记录，重复进入、重新挑战或销毁武器后均不会重新发放。
- 已装备武器时，新拾取和重复拾取都不再强制换装；在B背包主动选择。当前为默认装备时，首次可用武器仍自动装备。
- 四把前期武器在背包中说明用途、能量消耗、获取途径与水生克制。专属角色的装备限制继续生效。
- 商店购买前显示药品效果、武器基础伤害／能量、特殊能力和当前角色不可装备的提示。图标、价格、数量与等级锁保持可见。
- 大药品、技能瓶、经验结晶等拾取后补上获得提示；已有点击使用和快捷键功能保留。传送卷轴说明同步更新为第一～第五章。

### 继续旅程与重复挑战

- 前两章通关出口按E弹出选择：同章下一关、保存并返回主场景。章末提示下章入口；未通关不显示下一关。
- Esc重新挑战已通关的前期关卡现在会真正重置机关与遭遇，保留等级、装备、救援解锁与后续关卡入口。
- 读档区分“历史已通关”和“当前重玩尚未完成”，可继续重玩进度；不重复领取首通金币，也不重复领取引导装备。
