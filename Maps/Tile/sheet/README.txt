Adventurer's Kit
================

16 camp and exploration icons at 32x32 and 64x64, transparent PNG. Free.

Contents
  png_32/           16 icons at 32x32
  png_32_x4/        the same, nearest-neighbour x4 (128px)
  png_32_x8/        x8 (256px)
  png_64/           16 icons at 64x64
  png_64_x4/        x4 (256px)
  png_64_x8/        x8 (512px)
  atlas/            atlas_32/atlas_64 .png + .json frame coordinates
  palette/          palette .png .txt .hex .gpl (Aseprite, Lospec, GIMP)
  preview/          preview images, not for use in game
  LICENSE.txt       usage terms

Both sizes are cut from the source art at their own resolution, so the 64px
set carries genuinely more detail — it is not an upscale of the 32px set.

Contents: backpack, bedroll, tent, campfire, cooking pot, iron key, chest,
coin pouch, sapphire, map, compass, torch, bucket, signpost, grappling hook,
spyglass.

Notes
  - Pixel art: scale with NEAREST NEIGHBOUR only. Bilinear or bicubic
    filtering will blur it.
  - Alpha is fully binary (0 or 255), so alpha testing works.
  - All 16 share one 64-colour palette.

Same hand and same folder layout as my paid packs, so anything you build on
top of these will still line up if you add the others later.

AI disclosure: base artwork generated with Google Gemini, then cut,
downscaled, palette-quantised and curated by hand.
