# 分类背包

- **B / I** 或 HUD 的“背包 B”按钮打开；**B / I / Esc** 关闭。打开期间暂停战斗，关闭后继续。
- **Esc** 单独打开暂停设置，包括音量、返回和保存退出；与背包、地图、NPC 对话、死亡弹窗互斥。
- **道具**：持有的护甲、护符等，显示减伤属性和生效条件，持有时自动装备。
- **破甲战歌**：通关4-5永久解锁，按5、点击战斗快捷栏或背包道具按钮使用。30秒999真伤，每次关卡挑战一次；显示剩余秒数/本关已用。暂停冻结，离开或倒下结束；重试恢复次数，普通返回不恢复。
- **传送卷轴**：进入第四章永久解锁，旧第四章存档自动补齐。在“道具”页显示图标和“∞ 无限使用”，也可从Esc暂停菜单直接打开。可传送到第一～第四章主场景，不消耗次数或金币，遵守目的章节等级与角色限制。
- **中途离开**：子关卡Esc菜单可以“返回本章主场景”，未完成也可返回；保存当前关卡检查点，再进入继续，不发放通关奖励。
- **重新挑战本关**：重置当前未完成挑战（竞技场重置波次、BOSS、乐队站位），恢复队伍，保留等级、金币、武器、装备及历史通关奖励。与“重置存档 / 重新开始”是不同按钮。
- **药品**：生命、技能、绝杀药剂，显示数量，可直接使用；数量为零或状态已满时禁用按钮。
- **武器**：默认武器和已经取得的武器，显示贴图、伤害、消耗、射程及属性，可直接装备。关闭后 G 丢弃当前武器。
- **角色**：菲比、糯糯、坤坤，显示生命、能力和解锁条件；可直接切换已解锁且存活的角色。

界面 `UI/inventory.gd` 使用现有 `Campaign.profile`，无需新建存档。`Campaign.equip_weapon` 校验武器归属，`Campaign.select_character` 校验解锁、存活和施法状态；切换后立即更新玩家及存档。

## 宝箱与怪物碰撞校准

- `Combat/chest.tscn`：箱底对齐根节点，`InteractionArea/CollisionShape2D` 是贴合关闭箱体的 **32 × 26** 交互矩形，可在编辑器调整。它没有实体阻挡，也不参与武器受击。
- 宝箱按玩家与箱体边缘的距离判断交互，可达距离由 `interaction_reach` 设置；墙壁和封印门阻止隔墙开箱。开启后立即停用交互，动画结束时删除。
- `Characters/Definitions/*.tres`：`foot_size` / `foot_offset` 控制走路碰撞，`hurtbox_size` / `hurtbox_offset` 为身体受击的备用范围，`hurtbox_frames` 保存待机和移动各帧的身体矩形。攻击特效不会扩大受击范围。
- 怪物转身时以贴图的实际中心镜像受击范围，避免非对称贴图横向错位。十二种敌人/BOSS 已按可见像素校准，透明留白不计入身体范围。
- `Tools/audit_actor_bounds.gd` 与 `Tools/calibrate_actor_collisions.py` 是离线校准工具，游戏不调用。后续手工调整资源后不要直接重新运行覆盖。

验证：`Tests/inventory_collision_smoke.gd` 覆盖快捷键、暂停互斥、消耗/装备/切换、锁定及死亡角色限制、宝箱交互距离与隔墙限制、怪物帧与镜像碰撞。旧截屏脚本已清理；经验结晶的使用、数量、图标和读档由 `Tests/experience_item.gd` 验证。
